# Studio v3 視覺探索

入口：`index-studio-v3.html`。沿用 Business v2 的內容與互動，使用獨立的 CSS 與視覺腳本；原版保持可獨立開啟。

- 白色畫布、低彩度淺灰建議卡片、細邊框及深色送出按鈕。
- 首頁依序排列球體、問候、輸入框與現有三張建議卡片；對話中輸入框恢復底部。
- Sphere 使用使用者提供的第二段錄影，裁成正方形、縮至 384px、去除音軌，以正播／倒播銜接形成連續循環。素材：`assets/orb/gina-studio-orb.mp4`。
- 輸入時影片播放速度為 1.7 倍，停止輸入 700ms 後恢復；背景分頁、Agent 頁與對話頁暫停，減少動態偏好使用靜態畫面。
- 所有文案、對話模板及原應用程式邏輯沿用 v2。
